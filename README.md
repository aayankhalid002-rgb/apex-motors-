# APEX MOTORS — Car Showroom Demo

A responsive, frontend-only automotive showroom demonstration built with HTML, CSS and vanilla JavaScript.

## Run locally
1. Extract this ZIP.
2. Open the `APEX-MOTORS` folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.

## Included
- Premium showroom landing page and responsive navigation
- Vehicle inventory with SUV, Sedan and Sports category filters
- Vehicle search and sorting by price or model year
- Vehicle detail modal with sample specifications
- Enquiry form with browser-side required-field and email validation
- Mobile navigation, active-section navigation state, keyboard-accessible controls and scroll-reveal animations
- Hover effects, entrance motion and reduced-motion support
- Favicon and project documentation

## Demo limitations
This project is frontend-only. It has no backend, database, customer accounts, real booking system, email delivery, live inventory, or payment processing. The enquiry form only displays a confirmation in the browser; it does not send or save an enquiry on a server.

Vehicle names, specifications, mileage and PKR prices are illustrative sample content, not verified live listings or market valuations. Replace them with verified showroom data before any real commercial use.

Vehicle photography and web fonts load from external services and require an internet connection. If offline, local page structure and interactions remain available, but remote images and fonts may not load.
